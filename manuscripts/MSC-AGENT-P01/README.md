# MSC-AGENT-P01: Causal Event Provenance and TOCTOU Failures in Asynchronous Assistive Agents

**Stan:** kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników.

Can causally versioned state snapshots reduce undetected time-of-check/time-of-use failures in asynchronous agents?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. Replay synthetic event streams with reordered updates, restarts and stale snapshots; compare timestamp-only logs, versioned snapshots and transactional baselines.

**Wynik główny:** Undetected stale-premise decision rate and detection latency.

**Bramka samodzielności:** NEW_CROSS_PROGRAM_IDEA_HOLD: no deployment to physical actuators or claim of new causality formalism before prior-art audit.
