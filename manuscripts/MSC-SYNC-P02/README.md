# MSC-SYNC-P02: Uncertain Android Camera Latency in Mobile Gaze-to-Game Alignment

**Stan:** kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników.

Can explicit camera-latency uncertainty improve temporal attribution of gaze to 2D game events?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. Use reference LED/visual timing markers and controlled frame buffering to quantify exposure-to-timestamp latency.

**Wynik główny:** Absolute timing error and coverage of uncertainty intervals for gaze-to-stimulus alignment.

**Bramka samodzielności:** IDEA_HOLD: do not duplicate the same synchronization method proposed under MSC-SYNC-P01.
