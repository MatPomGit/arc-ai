# MSC-AAL-P04: Safety-Constrained Local Intent Grounding for Ambiguous Smart-Home Commands

**Stan:** kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników.

Can a local language model abstain on ambiguous commands while preserving deterministic safety constraints?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. Construct a synthetic taxonomy of ambiguous and unsafe intents; compare deterministic parser, unrestricted language model and safety-gated grounding.

**Wynik główny:** Unsafe command execution rate in a simulator at fixed successful task coverage.

**Bramka samodzielności:** IDEA_HOLD: no physical actuator control without separate safety validation.

Wpis w programie jest propozycją dalszych badań. Nie stanowi prerejestracji, zgody na eksperymenty z udziałem ludzi ani decyzji o publikacji.
