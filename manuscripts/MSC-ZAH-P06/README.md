# MSC-ZAH-P06 — Model obliczeniowy wyglądu, zachowania i oczekiwań społecznych

**Working title:** *Predicting Social Uncanniness from Appearance, Motion and Contextual Expectation*.

**Status:** `IDEA_HOLD`, prospektywny manuskrypt metodologiczny. Brak danych eksperymentalnych, wyników i zamrożonego protokołu.

**Pytanie:** czy wykorzystanie stopnia realizmu wyglądu, dynamiki ruchu oraz kontekstowych oczekiwań poprawia przewidywanie reakcji obserwatorów na nowe awatary?

**Wynik główny:** błąd przewidywania niesamowitości na niezależnych osobach źródłowych, postaciach i scenariuszach. Baseline obejmują wygląd, ruch, prostą różnicę cech i model interakcyjny.

**Odrębność:** generalizacja obliczeniowa, a nie ponowna analiza opisowa eksperymentów MSC-ZAH-P02–P04. Wspólne stanowisko: [ST-08](https://github.com/MatPomGit/research-autopilot/blob/main/docs/portfolio/reorganizacja-systemu-badan/shared_research_platforms.md).
