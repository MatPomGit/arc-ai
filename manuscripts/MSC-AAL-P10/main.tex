\begin{abstract}
What minimum sensor configuration retains pre-specified activity identifiability after any single sensor failure? This paper proposes a methodological evaluation, not a validated effect. We define a primary outcome, an independent validation strategy and explicit stopping criteria. Results are unavailable; theoretical assumptions and data eligibility must be audited before study activation.
\end{abstract}
\section{Research problem}
What minimum sensor configuration retains pre-specified activity identifiability after any single sensor failure? The research is framed around a verifiable computational property rather than a change of application context alone. Its technical originality remains a hypothesis requiring a targeted literature review.
\section{Hypotheses and anticipated contribution}
H1 proposes that the candidate approach will improve the pre-specified primary outcome relative to a matched, non-trivial baseline. H2 proposes that the improvement, if observed, remains reliable under independent domains, fault conditions or held-out units. Neither hypothesis has been tested.
\section{Data, materials and eligibility}
Exhaustive small simulations and withheld household traces; single-sensor knockout. Data licensing, annotations, task comparability and reproducible split definitions are preconditions. Where authentic data are unavailable, only clearly labelled synthetic experiments are appropriate; simulated outcomes must never be reported as human or clinical measurements.
\section{Methods}
Compute distinguishing event traces across admissible activity sequences; compare greedy, random and optimization-based sensor subsets. All model selection and calibration must use training-only data; evaluation must avoid overlap between participants, sessions, households and temporal blocks as appropriate. Fixed seeds, environment manifests and source identifiers are required for repeatability.
\section{Evaluation protocol and statistics}
The primary outcome is: Minimal sensor count at fixed sensitivity and false-alarm constraints, plus unidentifiable-state proportion.. Analyses must specify the estimand, comparator, independent unit, confidence interval procedure, failure criteria and sensitivity checks before running confirmatory evaluation. Report both average performance and challenging edge cases.
\section{Results}
No empirical or simulated benchmark has yet been executed for this candidate publication. This section intentionally contains no numerical result, effect size, model comparison or inferred statistical significance.
