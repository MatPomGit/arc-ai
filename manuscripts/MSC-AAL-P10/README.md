# MSC-AAL-P10: Identifiability-Aware Minimal Sensor Sets for Reliable ADL Monitoring

**Stan:** kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników.

What minimum sensor configuration retains pre-specified activity identifiability after any single sensor failure?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. Compute distinguishing event traces across admissible activity sequences; compare greedy, random and optimization-based sensor subsets.

**Wynik główny:** Minimal sensor count at fixed sensitivity and false-alarm constraints, plus unidentifiable-state proportion.

**Bramka samodzielności:** NEW_CROSS_PROGRAM_IDEA_HOLD: feature selection without identifiability analysis is not a distinct contribution.

Wpis w programie jest propozycją dalszych badań. Nie stanowi prerejestracji, zgody na eksperymenty z udziałem ludzi ani decyzji o publikacji.
