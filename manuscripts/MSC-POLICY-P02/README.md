How much can adaptive acquisition distort policy-value estimates when observation missingness depends on decisions?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. **Wynik główny:** Bias of estimated treatment-policy value and interval coverage against the simulation truth.
