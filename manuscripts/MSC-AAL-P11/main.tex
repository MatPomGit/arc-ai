\begin{abstract}
When should a model withhold identity attribution while retaining reliable activity classification? This paper proposes a methodological evaluation, not a validated effect. We define a primary outcome, an independent validation strategy and explicit stopping criteria. Results are unavailable; theoretical assumptions and data eligibility must be audited before study activation.
\end{abstract}
\section{Research problem}
When should a model withhold identity attribution while retaining reliable activity classification? The research is framed around a verifiable computational property rather than a change of application context alone. Its technical originality remains a hypothesis requiring a targeted literature review.
\section{Hypotheses and anticipated contribution}
H1 proposes that the candidate approach will improve the pre-specified primary outcome relative to a matched, non-trivial baseline. H2 proposes that the improvement, if observed, remains reliable under independent domains, fault conditions or held-out units. Neither hypothesis has been tested.
\section{Data, materials and eligibility}
Hold out households, perturb sensor availability and quantify selective risk. Data licensing, annotations, task comparability and reproducible split definitions are preconditions. Where authentic data are unavailable, only clearly labelled synthetic experiments are appropriate; simulated outcomes must never be reported as human or clinical measurements.
\section{Methods}
Measure class-conditional attribution uncertainty in simulated multi-occupant and licensed labeled household data; compare forced attribution and selective abstention. All model selection and calibration must use training-only data; evaluation must avoid overlap between participants, sessions, households and temporal blocks as appropriate. Fixed seeds, environment manifests and source identifiers are required for repeatability.
\section{Evaluation protocol and statistics}
The primary outcome is: Incorrectly addressed alerts per event at fixed minimum attribution coverage.. Analyses must specify the estimand, comparator, independent unit, confidence interval procedure, failure criteria and sensitivity checks before running confirmatory evaluation. Report both average performance and challenging edge cases.
\section{Results}
No empirical or simulated benchmark has yet been executed for this candidate publication. This section intentionally contains no numerical result, effect size, model comparison or inferred statistical significance.
