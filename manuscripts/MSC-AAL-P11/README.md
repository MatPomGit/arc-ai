# MSC-AAL-P11: Selective Resident Attribution Under Unidentifiable Multi-Occupant ADL Signals

**Stan:** kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników.

When should a model withhold identity attribution while retaining reliable activity classification?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. Measure class-conditional attribution uncertainty in simulated multi-occupant and licensed labeled household data; compare forced attribution and selective abstention.

**Wynik główny:** Incorrectly addressed alerts per event at fixed minimum attribution coverage.

**Bramka samodzielności:** NEW_CROSS_PROGRAM_IDEA_HOLD: safety-critical unpersonalized alerts remain a separate channel.
