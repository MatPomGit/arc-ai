# MSC-AAL-P01: Privacy-Aware Fault-Tolerant Edge AI Architecture for Assisted Living

Stan: kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników. Właściciel naukowy: Mateusz Pomianek.

[Manuskrypt koncepcyjny](main.tex) opisuje proponowaną architekturę, model awarii, granice zaufania i metodologię benchmarku. [Plan badań](study.yaml) zawiera definicje wyniku głównego i hipotez. Badanie zakłada sparowane scenariusze syntetyczne, bez uczestników.

Wynik główny: odsetek zdarzeń bez prawidłowego efektu logicznego do ustalonego terminu rekoncyliacji, przy wspólnych ograniczeniach funkcjonalnych i prywatności. Czas przywracania funkcjonalności jest wynikiem drugorzędowym.

Status pozostaje concept / deferred. Aktywacja wymaga potwierdzenia nowości, wykonalności, zamrożenia protokołu i decyzji właściciela. Nie jest to prerejestracja ani decyzja o publikacji.
