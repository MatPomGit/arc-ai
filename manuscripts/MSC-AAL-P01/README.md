# MSC-AAL-P01: Privacy-Aware Fault-Tolerant Edge AI Architecture for Assisted Living

**Stan:** kandydatura badawcza (IDEA_HOLD), bez zatwierdzonego eksperymentu i bez potwierdzonych wyników.

How does a local-first event architecture maintain availability and bounded disclosure during network faults?

[Manuskrypt koncepcyjny](main.tex) definiuje problem, hipotezy, protokół i ograniczenia. [Plan badań](study.yaml) opisuje wynik główny i walidację. Create reproducible virtual smart-home traces, network faults and failover; compare cloud-first and local-first architectures.

**Wynik główny:** Validated event-loss and recovery-time performance at matched disclosure and functional constraints.

**Bramka samodzielności:** SOURCE_PLANNED_ARTICLE: a systems architecture alone is insufficient without independent evaluated technical properties.
